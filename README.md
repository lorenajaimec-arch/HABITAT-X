# HABITAT-X | Earth Analog Explorer

Interactive Gradio prototype for exploring terrestrial analog sites for the lunar South Pole, Arcadia Planitia, and Utopia Planitia. Includes catalogs, region and characteristic filters, an interactive map, and an illustrative 3D surface.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

## Project limitations

Category coverage measures the fraction of the selected planet-region's themes represented in the curated catalog. It is not physical similarity, construction suitability, or a NASA measurement. Locations are approximate and the 3D illustration is not a measured terrain model. Source links are listed with each catalog entry.
